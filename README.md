# lianghua

一个基于 Python 的通用 Agent 项目骨架。

## 目录说明

- src/lianghua_agent: 主代码
- src/lianghua_agent/agents: Agent 逻辑
- src/lianghua_agent/tools: 工具封装
- src/lianghua_agent/workflows: 工作流编排
- src/lianghua_agent/models: 数据模型
- src/lianghua_agent/config: 配置管理
- src/lianghua_agent/utils: 通用工具
- prompts: Prompt 模板
- tests: 测试
- scripts: 启动和辅助脚本
- docs: 文档
- examples: 示例
- data: 本地数据
- knowledge: 知识库资料
- logs: 日志输出
